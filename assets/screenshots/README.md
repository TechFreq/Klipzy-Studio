# Screenshots

Drop your UI screenshots in this folder, then they'll show up in the main
[README](../../README.md) "Screenshots" section.

**Expected filenames** (used by the README — match these names so the images
appear automatically):

| Filename | What to capture |
|----------|-----------------|
| `clipper.png` | The main "Long Form to Shorts" screen (step 1–2, drop zone / clipping options) |
| `generated-clips.png` | The "Generated Clips" grid with a few viral clips + captions |
| `caption-editor.png` | The caption editor / live portrait preview |
| `setup.png` | The Setup screen (hardware detect, models, GPU acceleration) |

Tips:
- PNG or JPG both work. Aim for a reasonable size (e.g. 1280–1920px wide); very
  large files bloat the repo.
- After adding the files here, commit and push. On `develop`, merge into `main`
  when you want them live on the public page.
- Prefer not to commit images? You can instead drag an image straight into the
  README editor on github.com — GitHub uploads it and inserts a link for you.
