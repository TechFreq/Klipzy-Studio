# Screenshots

These images are shown in the main [README](../../README.md) "Screenshots" section.
To refresh one, just replace the file with the same name (keep the filenames so the
README keeps working).

| Filename | What it shows |
|----------|---------------|
| `generated-clips.png` | The "Viral Clips Generated" grid (AI hooks, titles & descriptions) |
| `clipping-options.png` | Clipping & Style options (durations, aspect ratio, framing, audio, detection) |
| `caption-customization.png` | CapCut-style caption customization + live portrait preview |
| `setup-system.png` | Setup & System (hardware, GPU/CUDA acceleration, model recommendations) |
| `ai-edit-chat.png` | The local AI Edit Chat |
| `projects-home.png` | The Projects landing screen |

Tips:
- PNG or JPG both work; keep files a reasonable size (very large images bloat the repo).
- Add/replace on `develop`, then merge into `main` to publish to the public page.
- No-repo alternative: drag an image into the README editor on github.com and it hosts it for you.
