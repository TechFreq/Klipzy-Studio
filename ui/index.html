🔧 Dependency Checker

Ollama is Klipzy's local AI provider. You do not need to build or configure your own server: install Ollama once, and Klipzy connects to its local service when AI analysis or chat is enabled. LM Studio is optional only if you prefer another local provider.

Missing something? Click Install for one item, or Install All Recommended to set up everything missing at once (winget / Homebrew / pip). This can take several minutes.

🧹 Maintenance

Klipzy caches transcripts so re-processing the same video is instant. Clearing it frees space and forces a fresh transcription next time. Rendered clips are never touched. Deleting a project also removes its rendered clips automatically.
